# UI Contract: 공개 화면 (014)

화면마다 «반드시 있어야 하는 것»을 적는다. 구현과 검증(quickstart.md)은 이 표를 기준으로 한다. 시안: `docs/design/mockups_2026-11-26_v4/dirs/f01.html`.

## 공통

| 항목 | 계약 |
|---|---|
| 테마 | `.pica-public[data-pica-theme="paper"]`. 값은 BRAND_GUIDE 2절 «화면 팔레트» |
| 글꼴 | 본문 Pretendard / 묶음 머리·상세 제목·공간 이름 Gowun Batang 700 / 숫자·날짜 Space Grotesk |
| 맨 위 줄 | pica 로고(홈 링크) · 찾기 · 내 정보(로그인 전이면 로그인). 관리자면 관리자 화면 링크를 «내 정보» 메뉴 안에 둔다 |
| 포스터 칸 | `PosterOrText` 한 가지로 그린다. 입력은 `poster_image_url`, `poster_placeholder`, 제목, 날짜, 출처 이름. 이미지를 불러오지 못하면 글자 포스터로 바꾼다 |
| 글자 포스터 | 날짜(Space Grotesk, 가장 큼) · 제목(2~3줄) · «정보: 출처 이름». 포스터가 없는 행사면 «포스터 없음»을 작게 적는다 |

## 홈 `/` (지역 페이지 `/region/[name]`도 같은 화면)

| 순서 | 요소 | 계약 |
|---|---|---|
| 1 | 칩 줄 | 기간⌄ · 지역⌄ · 분야⌄ · 아이와 + «필터». 화면 위에 붙는다(sticky). 바꾸는 주소 매개변수는 지금과 같다(`date`·`region`·`category`·`kids`·`ended`·`q`) |
| 2 | 날짜 묶음 | `orderFeed()` 결과 순서. 머리: 명조 묶음 이름 · 건수 · 정렬 기준 · «모두 보기» |
| 3 | 선반 | 좌우로 넘기는 칸. 첫 묶음 칸 폭 104px, 나머지 묶음은 시안 폭. 묶음마다 앞 12장 |
| 4 | 상시·장기 | 접힌 한 줄 «상시·장기 N건 ⌄» |
| 5 | 소식 받기 | 뉴스레터·키워드 알림 폼은 남긴다(FR-004). 새 색의 옅은 띠로 바꾼다 |
| 떠 있음 | «지도» 버튼 | 화면 아래 가운데. 누르면 지도 시트 |

- `?section=<key>`: 그 묶음만 세로 목록으로 보인다(«모두 보기»). 필터 매개변수는 유지한다.

## 지도 시트 (홈 안)

| 요소 | 계약 |
|---|---|
| 열기 | «지도» 버튼을 누를 때. 그 전에는 지도 스크립트를 요청하지 않는다 |
| 머리 | 켠 필터 요약 · «N건 · 장소 N곳» · 내리기 |
| 지도 | 장소별 핀(행사 수). 좌표 없는 장소는 핀 없음 |
| 핀 선택 | 지도 아래 작은 선반(그 장소 행사) + «공간 정보 ›»(`/venues/[id]`) |
| 장소 목록 | 위치 허락 시 가까운 순, 아니면 행사 수 순. 맨 아래 «위치 정보 없음» |
| 닫기 | 내리기 버튼 · «목록» 버튼 · 뒤로 가기 · 바깥 어두운 곳 누르기 |

## 상세 `/events/[id]`

| 순서 | 요소 | 계약 |
|---|---|---|
| 1 | 포스터 띠 | `#EBE4D7` 띠 가운데 포스터(원본 비율) 또는 글자 포스터. 누르면 크게 보기(지금 `PosterViewer`) |
| 2 | 요약 카드 | 분야 꼬리표(+아이와) · 명조 제목 · 날짜 · 장소 |
| 3 | 버튼 | «길찾기»(외부 지도) · «공간 정보»(`/venues/[id]`, 장소가 연결된 경우만) |
| 4 | 정보 줄 | 시각 · 관람료 · 관람(연령) · 공간(객석·휴관일) · 출처(이름·확인한 날) · 주최·주관 · 단체 제공 표시 |
| 5 | 피카가 본 이유 | 초록 테두리. 값이 있을 때만 |
| 6 | 안내 문구 | 「수집한 정보를 정리한 것이라 바뀔 수 있어요…」 + «피카가 고르는 기준» 링크 |
| 7 | 상세 안내 | 지금처럼 설명이 정보 칸으로 다 옮겨지지 않았을 때만(개인 휴대전화 가림 유지) |
| 8 | 같은 주 행사 | 같은 지역·같은 주 |
| 9 | 오류 신고 · 캘린더 추가 | 지금 기능 유지 |
| 고정 | 아래 막대 | 찜 · 공유 · «원본 안내 페이지 열기»(없으면 «단체 제공 — 원본 안내 없음») |
| 없음 | 작은 지도 | 넣지 않는다(운영자 «그냥 버튼») |

## 공간 `/venues/[id]` · 단체 `/orgs/[id]`

| 순서 | 요소 | 계약 |
|---|---|---|
| 1 | 머리 띠 | «공간 · 지역»(단체는 «기관/단체 · 지역») · 협약 배지(`partner_since` 있을 때) · 명조 이름 · 객석 · 다가오는 행사 수 · 휴관일 |
| 2 | 버튼 | «길찾기»(공간만) · «일정 캘린더로 받기»(구글·애플) |
| 3 | 다가오는 행사 | 선반 + «모두 보기» |
| 4 | 상시 | 상시·장기 행사 한 줄씩 |
| 5 | 이곳 행사를 여는 곳(공간만) | 기관=건물 아이콘, 단체=사람 아이콘, 협약=초록 도장. 맡은 일 · 건수. 아래 범례 |
| 6 | 지난 행사 | 최근 1년 날짜·제목 줄 |
| 7 | 안내 문구 | 지금 문구 유지 |

## 내 정보 `/me`

| 순서 | 요소 | 계약 |
|---|---|---|
| 1 | 프로필 | 닉네임 · 로그인 계정 · «고치기» |
| 2 | 찜한 행사 `#saved` | 선반 + «모두 보기»(세로 목록) |
| 3 | 내 지역 | 지역 고르기 · «내 지역 먼저 보기» 켜고 끄기(`profiles` 지금 칸) |
| 4 | 관심 분야 | 칩 여러 개 고르기(`profiles.interests`) |
| 5 | 캘린더로 받기 | 구글 · 애플·기타(지금 `/calendar.ics` 주소) |
| 6 | 알림 `#settings` | 새 행사 알림 · 이메일 알림(지금 칸) |
| 7 | 링크 | 단체·공간 안내(`/partners`) · 피카가 고르는 기준(`/about`) |
| 8 | 계정 | 가입일 · 이용약관 · 개인정보 처리방침 · 로그아웃 |

- `/saved` → `/me#saved`, `/settings` → `/me#settings` (서버 리디렉트). `/calendar`는 그대로 열리고 새 색만 입는다.
- 로그인 전 `/me`: 로그인 안내와 로그인 버튼.

## 관리자 (배치 그대로, 입력만 더함)

| 화면 | 더하는 것 |
|---|---|
| 행사 상세 관리 | 포스터 옆 «안내 그림으로 표시 / 풀기». 같은 지문을 쓰는 행사 수를 함께 보인다 |
| 대시보드 또는 인박스 | «안내 그림 후보»: 같은 지문을 3개 넘는 공개 행사가 쓰는 그림 목록 |
| 공간·단체 | «협약 맺음(날짜) / 풀기» |
