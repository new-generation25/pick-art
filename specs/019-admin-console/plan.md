# 019 계획 — 관리자 화면 개편 (운영 콘솔)

명세: [spec.md](spec.md) · 작성 2026-11-27 · 상태: 운영자 승인 전

## 요약

관리자 화면을 «수집을 돌리고 하나씩 승인하는 화면»에서 «자동화가 넘긴 것만 처리하고, 자동화가 한 일을 확인하는 화면»으로 바꾼다.
메뉴 13곳을 5곳으로 줄이고, 7단계(A0~A6)로 나눠 단계마다 따로 배포한다. 앞 단계만 해도 쓸모가 있게 순서를 잡았다.

## 메뉴 (5곳)

1. **오늘 할 일** `/admin` — 정기 실행 한 줄 + 사람 몫 목록
2. **대기함** `/admin/queue` — 공개 판단 · 받은 것 · 정보 다듬기
3. **행사** `/admin/events` — 찾기 · 새 행사 · 숨김
4. **출처·단체** `/admin/sources` — 출처 · 단체 · 공간
5. **현황** `/admin/status` — 회차 요약 · 경고 · 방문·노출 · 인스타 · 알림·회원 · 저장공간

휴대폰에서는 화면 아래 탭 5개, PC에서는 왼쪽 또는 위 메뉴. 대기함·경고에는 건수 숫자를 붙인다.

## 단계와 끝 조건

단계마다 `/speckit-tasks` → 구현 → 로컬 빌드·화면 확인 → 운영자 «배포해» → 운영 주소 확인 순서로 간다.

## 데이터·수집기 변경

- **A0** `orgs.partner_note` 익명 읽기 막기: 칸 권한을 거두거나(익명·회원 역할에서 `partner_note` SELECT 제외) 관리자 전용 표로 옮긴다. 공개 화면은 `partner_since`만 쓴다.
- **A4** `events`에 `hidden_reason`·`hidden_by`·`hidden_at`·`keep_visible`(되돌린 뒤 다시 숨기지 않음). `dedupe_published.py`·`hide_events.py`가 이유를 적고 `keep_visible`을 지킨다. 지금 숨김 76건은 `collector/logs/dedupe/`·`logs/hidden/` 백업에서 이유를 옮겨 적는다.
- **A5** `whitelist`에 `consent`(none·temporary·standing·withdrawn)·`consent_at`·`consent_evidence`·`paused_reason`. `role`·`score`·`score_detail`은 운영 DB에는 있는데 마이그레이션 파일에 없다 → `add column if not exists`로 기록을 맞춘다. `triage_review.py`의 상시 동의 판정과 정기 실행의 건너뛰기가 새 칸을 읽는다.
- **A6** `ops_snapshots`에 `routine_steps` 줄(최근 14회의 단계별 요약). 관리자만 부를 수 있는 집계 함수 2개(알림·회원, 숫자만 돌려줌).
- 새 표·칸은 처음부터 관리자 정책을 갖고 만든다(헌장 III).

## 헌장 점검

- **I 확인한 정보만**: 운영자가 검증 없이 공개하는 길을 넓히지 않는다(«단체 제공»만). 날짜를 고친 건은 다음 검증에 다시 올린다. 삭제 대신 숨김.
- **II 브랜드**: 관리자 화면도 종이 테마 색·글꼴. «픽아트» 표기 없앰. 지역은 경남 18 시군 + 부산(구·군)으로 나눠 쓴다.
- **III 보안**: 익명으로 읽히는 협약 메모를 A0에서 막는다. 알림·회원은 숫자만. 이 PC를 실행하는 API(`/api/collector/status`)를 없앤다.
- **IV AI 최소 개입**: AI 프롬프트 화면을 없앤다(AI 추출 꺼짐). 대기 카드에 «어느 규칙으로 왔는지·근거»를 보인다.
- **V 끝 조건**: 단계마다 위 표의 끝 조건. 화면 변경은 휴대폰 폭 확인, 배포는 운영 주소 확인.

## 위험과 대응

- 인박스(882줄)를 한 번에 바꾸면 운영이 멈출 수 있다 → A3은 새 주소(`/admin/queue`)에 만들고, 확인이 끝난 뒤 옛 인박스를 없앤다.
- 공통 행사 양식이 세 곳의 저장 규칙을 합친다(리플렛은 «단체 제공» 출처, 후보는 원본 게시물 연결) → 양식은 칸만 맡고 저장 규칙은 호출하는 쪽이 넘긴다.
- 동의 단계를 옮겨 적을 때 글자 해석이 틀릴 수 있다 → 옮기기 전후 표를 만들어 19곳을 운영자가 한 번 본다.
- 다른 세션(017 카카오·인스타)이 같은 관리자 파일을 고칠 수 있다 → 단계 시작 때 알리고, 배포는 이 세션만 한다.
