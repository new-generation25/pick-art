# Research: 공개 출시 준비 보완

## R1. 개인정보처리방침에 넣을 항목

- **Decision**: 개인정보보호법 제30조(처리방침 공개)의 일반 기재 사항을 따른다 — 처리 목적, 처리 항목, 보유·이용 기간, 파기 절차·방법, 제3자 제공, 처리 위탁, 정보주체 권리와 행사 방법, 안전성 확보 조치, 보호책임자, 변경 고지·시행일. 자동 수집 장치(쿠키·로컬 저장소) 사용 여부도 적는다(Supabase 로그인 세션을 브라우저 저장소에 보관).
- **Rationale**: 일반 공개 웹서비스의 표준 구성이고, 구글 OAuth 정식 게시 심사도 처리방침 주소를 요구한다.
- **Alternatives**: 외부 생성기(개인정보보호위원회 처리방침 만들기) 결과를 붙이기 — 실제 수집 항목과 어긋나기 쉬워, 코드 대조로 직접 작성하고 법률 검토 전 초안임을 운영자 메모로 남긴다.
- **실제 수집 항목 대조 (코드 기준)**
  - 구글 로그인: 이메일, 구글 계정 식별자(Supabase Auth가 보관), 이름·프로필 사진은 구글이 넘기지만 서비스 화면·DB에 쓰지 않음 → "인증 업체가 보관"으로 기재
  - profiles: 닉네임, 지역, 관심 분야, 알림 설정, 내 지역 자동 적용, 전화번호(선택), 역할
  - subscribers: 이메일(뉴스레터) / keywords: 이메일 + 키워드
  - 처리 위탁: Supabase(인증·DB·파일 저장), Vercel(호스팅), Google(로그인)
  - 쿠키·저장소: 로그인 세션(브라우저 저장소), 화면 설정은 저장하지 않음

## R2. 공유 미리보기 기준 주소

- **Decision**: `metadataBase`를 `https://pick-art.vercel.app`로 하되, 환경 변수 `NEXT_PUBLIC_SITE_URL`이 있으면 그것을 쓴다(나중에 도메인을 사도 코드 수정 없이 바꿈). 로컬에서는 `http://localhost:3000`.
- **Rationale**: Next.js는 `metadataBase` 기준으로 미리보기 이미지·정규 주소를 절대 주소로 만든다. 지금 값이 localhost라 배포에서 틀린 주소가 나간다.
- **Alternatives**: `VERCEL_URL` 사용 — 배포마다 바뀌는 미리보기 주소라 공유용으로 부적합.

## R3. sitemap 범위·캐시

- **Decision**: 홈 + 공개(`PUBLISHED`)이면서 종료일이 오늘 이후인 행사 상세. 1시간 재검증(`revalidate = 3600`). 익명 키로 읽으므로 RLS가 비공개를 자동 제외.
- **Rationale**: 공개 피드 기본 조건과 같아 SC-004 비교가 쉽다.

## R4. 404 처리

- **Decision**: 행사 상세에서 행사가 없으면(삭제·비공개) `notFound()`를 호출해 `not-found.tsx`를 404 상태로 보여 준다. 비공개 행사는 RLS 때문에 익명 조회 결과가 없으므로 같은 경로로 404가 된다.
- **Rationale**: 지금은 같은 화면에 문구만 띄우고 200을 돌려준다. 검색엔진·공유 미리보기에 "없는 페이지"가 정상 페이지로 잡힌다.

## R5. 이메일·비밀번호 가입 제거

- **Decision**: 로그인 화면에서 이메일·비밀번호 입력을 빼고 소셜 로그인 버튼만 둔다. `/signup`은 `/login`으로 영구 이동(redirect). Supabase의 이메일 공급자 설정은 이번에 바꾸지 않는다(대시보드 설정 변경은 범위 밖, 화면 진입로만 닫음).
- **Rationale**: 사용자 결정(소셜 로그인만, 카카오 추후). 가입 3단계 화면은 구글 로그인 흐름에만 연결돼 있어, 이메일 가입은 지역·관심 분야를 건너뛴다.
- **Risk**: 이메일로 가입한 기존 계정이 있으면 로그인 경로가 사라진다 → 구현 전에 `auth.users`의 공급자별 수를 확인한다(있으면 사용자에게 알리고 보류).

## R6. 대표 미리보기 이미지

- **Decision**: 1200×630 정적 PNG를 브랜드 가이드 색(신문지 바탕·먹·리소 파랑·형광 분홍)과 워드마크로 만든다. 행사 상세는 행사 포스터를 쓰고, 없으면 이 이미지.
- **Rationale**: 브랜드 가이드 4절(로고), 13절(AI 이미지 지양) — 텍스트·도형만으로 HTML 렌더링해 PNG로 굽는다.
