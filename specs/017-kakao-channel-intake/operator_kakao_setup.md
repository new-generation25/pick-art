배포(«피카 앱 개선» 세션)가 끝나 `https://picka.news/api/kakao/skill` 이 열린 뒤에 한다.
✋ 표시는 **운영자만** 할 수 있는 단계다(비밀값 입력은 Claude가 하지 않는다 — 비밀값을 남의 화면 칸에 넣는 일은 Claude 안전 규칙상 금지). 나머지는 Claude가 MAX 브라우저로 할 수 있다(운영자 승인 뒤).

## 0. 이미 된 것 (11/26)
- 챗봇 관리자센터에 봇 **피카 행사 제보** 만듦 — https://chatbot.kakao.com/bot/6b07e404e3146b3ebc754f8b (상태 «준비», 채널 연결 안 함)
- 설정 › 운영 채널 목록에 **피카(@pickanews) «사용 가능»** 확인(연결은 안 누름)
- 스킬 비밀값: 운영자 PC `F:\projects\pick-art\collector\.env.local` 의 `KAKAO_SKILL_KEY=` 줄. DB에는 해시만 들어가 있다.

## 1. 스킬 만들기 (✋ 헤더 값)
1. https://chatbot.kakao.com/bot/6b07e404e3146b3ebc754f8b → 왼쪽 **스킬 › 스킬 목록 › 생성**
2. 스킬 이름 `피카 제보 서버`, URL `https://picka.news/api/kakao/skill`
3. **헤더값 입력**: 키 `x-pica-skill-key`, 값 = 메모장으로 `collector\.env.local` 을 열어 `KAKAO_SKILL_KEY=` 뒤 글자 전체를 복사해 붙여 넣기 ✋
4. «기본 스킬로 설정» 체크 → 저장
5. (선택) 같은 화면 «스킬 서버로 전송» 시험 — 응답에 `"version":"2.0"` 이 오면 연결된 것

## 3. 채널 연결·배포 (Claude가 할 수 있음 — 운영자 승인 필요: 채널 설정 변경)
1. 봇 **설정 › 카카오톡 채널 연결 › 운영 채널 선택하기 › 피카** → 저장
2. 왼쪽 **배포 › 배포** (처음은 전체 배포, 최대 30분, 시작하면 멈출 수 없음)
3. 채널 관리자(https://business.kakao.com/space/10805734) 에서 채널 **공개·검색 허용** 켜기 — 운영자가 결정. 비공개 채널은 챗봇 연결이 안 된다는 devtalk 답이 있었으나 공식 문서로는 확인 못 함(연결 화면에는 «사용 가능»)
4. 채팅방 메뉴를 쓰려면 «커스텀 메뉴»(리스트 메뉴는 챗봇과 함께 못 씀)

## 4. 시험 (✋ 운영자 휴대폰)
1. 카카오톡에서 `pickanews` 검색 또는 https://pf.kakao.com/_xoxdxkvX/chat → 채팅방
2. 아무 글 → «동의하고 보내기» → 리플렛 사진을 채팅창에 그냥 보내기(시험용이면 `specs/017-kakao-channel-intake/captures/test_leaflet.jpg`). 채널이 비공개면 «찾을 수 없는 채널» — 파트너센터 대시보드에서 공개·채팅 사용을 켠다
3. «사진 1장 받았어요» 답이 오면 Claude에게 알려 주기 → Claude가 검토함(https://picka.news/admin/leaflets)·버킷을 확인하고 verification.md 에 기록, 시험 데이터 삭제
