## User Stories

1. **피카가 본 이유 (P1)** — 관리자가 상세 화면에서 행사마다 한 줄(120자)을 쓰면, 제목 바로 아래에 «피카가 본 이유» 줄로 보인다. 비우고 저장하면 사라진다. 작은 무대를 큰 무대와 같은 무게로 소개하기 위한 자리다(헌장 II).
2. **휴관일 (P2)** — 전시 상세의 정보 표에서 «장소» 다음 줄에 그 장소의 휴관일 원문(예: «매주 월요일, 1월 1일»)을 보여 준다.
3. **객석 수 (P2)** — 공연 상세의 정보 표에서 «장소» 다음 줄에 «객석 N석»을 보여 준다.

## Requirements

- FR-001 `events.pica_note` text, 120자 이하(CHECK). 관리자만 쓴다(기존 events 관리자 수정 RLS). 공개 화면은 읽기만.
- FR-002 `venues.closed_days` text 80자 이하, `venues.capacity` integer 1~100000. 공개 뷰 `public_venues`에 두 칸을 더하고 읽기 권한만 다시 건다(익명 쓰기 불가).
- FR-003 장소 값은 공식 안내(장소 누리집·공고)로 확인한 것만 넣는다. 값이 없으면 줄을 만들지 않는다. 추측하지 않는다(헌장 I).
- FR-004 휴관일은 전시에만, 객석은 공연에만 보인다.
- 마이그레이션: `supabase/migrations/20261126040000_pica_note_venue_info.sql` (적용 완료, 되돌리는 방법은 파일 머리에)
