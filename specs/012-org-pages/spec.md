# Feature Specification: 단체·공간 페이지와 월간 노출·클릭 증빙

**Feature Branch**: `revive/2026-10` (명세 `specs/012-org-pages`) | **Created**: 2026-11-26 | **Status**: 구현·로컬 검증 완료 — 운영자 11/26 «모두 진행해»(시장조사 세션 입력, 기록 확인): 새 표, 동의 전 소규모 단체 페이지는 검색 제외로 공개, 동의서 문장 그대로. 월간 증빙은 011 «노출·클릭» 화면의 단체 고르기·CSV

**Input**: 시장조사 세션 요청(사용자 11/26 「앱 개선에 넘겨」). KOPIS 사각지대(전산예매가 아닌 공연, 전시) 소규모 공연·전시를 모으는 공공 데이터 사업의 실적(협약 단체 수, 사각지대 등록 건수). 단체에게 «이렇게 나가고 있습니다 + 동의서 한 장»을 보낼 때 쓸 페이지. 디자인 개선 계획 D4(장소 화면)와 겹쳐 합친다.

## 단체를 가를 데이터 (2026-11-26 확인)

- `events.source`는 수집한 곳(KOPIS·창원문화재단 등)이지 공연 단체가 아니다.
- KOPIS: 상세 API가 주최(`entrpsnmH`)·주관(`entrpsnmS`)·기획(`entrpsnmA`)·제작(`entrpsnmP`)을 준다(예: 피비컴퍼니, (재)밀양문화관광재단). 지금 수집기는 저장하지 않는다 → 수집기에 저장을 더하고 공개 중인 KOPIS 행사 약 305건을 한 번 채운다.
- 인스타 출처: `ai_suggestion.account`·`role`(official/artist/group/informant)이 있다. 계정 = 단체.
- 기관 누리집 출처: 출처 기관이 곧 주최인 경우가 많다(문화재단·회관). 공간은 `venues`.

## User Stories

1. **공간 페이지 (P1)** — `/venues/[id]`: 그 장소의 다가오는·지난 행사, 휴관일·객석(009), 길찾기, 그 장소만 받는 캘린더 구독. 상세 «장소» 줄에서 연다.
2. **단체 페이지 (P1)** — `/orgs/[id]`: 그 단체가 주최·주관한(또는 그 계정이 올린) 공개 행사 목록, 지난 공연 이력, 출연진(KOPIS `cast`가 있으면), 원본 링크.
3. **월간 증빙 (P2)** — 관리자가 단체·월을 고르면 행사별 «노출(상세 조회)·클릭(원본·캘린더·공유)» 표와 단체 페이지 주소를 한 장으로 뽑는다(011 숫자 사용).
4. **동의서 준비 (P3, 발송은 운영자 승인 뒤)** — 단체 페이지 주소·요약과 필수 문장 두 개를 담은 안내문 초안.

## 요구사항

- FR-001 표 `orgs(id, name, kind[기관|단체|계정], insta_handle, kopis_name)`와 `event_orgs(event_id, org_id, role[주최|주관|기획|제작|게시])`. 이름 맞추기는 띄어쓰기·(재)·괄호를 지운 글자로 하고, 애매한 것은 운영자 확인 대기열로.
- FR-002 단체 페이지에는 이미 공개된 행사만 나온다. 동의가 필요한 소규모 계정(artist/group)의 «공개 전» 글은 나오지 않는다(헌장 II, 인박스 «동의 필요»).
- FR-003 동의 전 소규모 단체 페이지는 검색엔진에 올리지 않는다(`noindex`) — 운영자 결정에 따라 바꾼다.
- FR-004 증빙 표기는 «노출·클릭». «관객 수»·«예매»라고 쓰지 않는다.

## 끝 조건

- KOPIS 공개 행사의 주최·주관 채움률(목표 90% 이상)과 단체 수를 숫자로 보고
- `/venues/<id>`·`/orgs/<id>`가 열리고 상세 장소 줄·주최 줄에서 이어짐
- 시험 단체 하나의 11월 증빙 표가 011 숫자와 같음

## 정할 것 (운영자)

1. 새 표 `orgs`·`event_orgs` 만들기와 KOPIS 주최·주관 채우기(API 약 305회) 승인.
2. 동의 전 소규모 단체 페이지를 공개할지(검색 제외로) / 동의 뒤에만 만들지.
3. 동의서 필수 문장 두 개(«공연 정보는 단체의 것이며, 요청하시면 7일 안에 삭제합니다.», «공개 정보를 바탕으로 한 비식별 통계는 피카가 공공에 제공할 수 있습니다.»)를 그대로 쓸지.

## 남은 것 (검토 파일에 목록)

- 기관 누리집 출처는 출처 기관을 주최로 넣었다(창원문화재단 111건 등) — 대관 공연이면 실제 주최가 다를 수 있다.
- 철자만 다른 같은 단체(「(주)조이컬처」·「조이컬쳐」), 이름이 이름을 품는 8쌍, 같은 이름의 인스타 계정·기관 4쌍은 합치지 않았다 — 관리자 합치기 화면은 아직 없다.
- 단체에 보낼 동의서·안내는 초안(docs/partner)만 있고 발송은 운영자 승인 뒤.
