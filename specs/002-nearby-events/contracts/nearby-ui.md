# Contract: 「내 주변」 화면 (`/nearby`)

## 진입
- 공개 피드 머리말(필터 줄)과 모바일 하단에 「내 주변」 링크. 경로 `/nearby`.
- URL 쿼리(모두 선택): `r` 거리 km(`3`|`10`|`30`|`all`, 기본 `all`), `p` 기간(`today`|`weekend`|`week`|`2w`, 기본 `week`=오늘~7일), `c` 분야(기존 분야 값), `area` 지역 키(예: `부산 수영구`). **위도·경도 쿼리는 받지도 만들지도 않는다.**

## 상태와 화면
| 상태 | 화면 |
|---|---|
| 처음(지역 기억 없음) | 「내 위치로 찾기」 버튼 + 한 줄 안내(「위치는 거리 계산에만 쓰고 저장하지 않아요」) + 지역 고르기 |
| 위치 받는 중 | 버튼 자리에 진행 표시. 6초 넘으면 지역 고르기로 전환 |
| 위치 허용 | 기준 줄 「내 위치 기준」(정확도 1km 초과면 「내 위치 기준 · 약」) |
| 위치 거부·실패 | 지역 고르기 펼침. 오류 문구 대신 「지역을 고르면 그 중심에서 가까운 순으로 보여 드려요」 |
| 지역 선택 | 기준 줄 「○○ 중심 기준」, localStorage 저장 |
| 결과 0건 | 「가까운 곳에 이번 주 행사가 없어요」 + 「2주로 넓히기」 「거리 제한 풀기」 버튼 |
| 부산·경남 밖 | 가장 가까운 행사가 50km 넘으면 「부산·경남 행사만 소개해요」 안내 + 지역 고르기 |

## 목록 항목
- 순서: 직선거리 오름차순, 같으면 시작일(진행 중이면 종료일) 빠른 순.
- 표시: 날짜(가장 크게) · 제목 · 장소 · 거리(`850m`, `1.2km`, 정확도 낮으면 `약 1.2km`) · 분야.
- 버튼: 「네이버지도 길찾기」 하나(이동수단은 네이버지도 안에서 고름) + 작은 링크 「앱이 없으면 웹에서 보기」 → `contracts/naver-map-link.md`(2026-11-21 운영자 결정).
- 좌표 없는 행사: 목록 끝 「거리 확인 안 됨」 묶음, 거리 대신 시군 이름. 길찾기는 장소 이름 검색으로.
- 장소가 아예 없는 행사(`venue` 빈 값·온라인): 목록에서 뺀다.

## 데이터 요청
- 서버에서 한 번: 기간 안 `PUBLISHED` 행사 + `public_venues`의 `lat,lng`(조인). 위치는 요청에 포함하지 않는다.
- 거리 계산·정렬·필터는 브라우저에서.
