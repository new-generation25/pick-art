## 1. 원칙 6개와 근거

1. **AI가 만든 것처럼 보이면 진다.**
   - 시청자는 AI 영상을 더 좋아하지 않고, 이질감 때문에 거부하기도 한다(영상 17).
   - 틱톡 2만 1천 편 분석에서 AI 음성을 쓴 영상은 공유가 7.4% 낮았다(research 15).
   - 매끈한 광고 느낌보다 날것·사람 느낌이 낫다(영상 11·14·15·17).
   - 2026-11-19 피카 시안(퀴즈·0원 도장·룰렛)은 운영자가 「AI 티가 많이 난다」며 쓰지 않았다.
2. **보여 주고, 설명은 나중에.**
   - 사람이 만든 레퍼런스 릴스는 소재를 먼저 읽히고, 9.8초가 지나서야 메시지를 말한다(research 21).
   - 첫 화면에 결론부터 쓰는 구성은 자동 생성물처럼 보인다.
3. **제목은 처음부터 끝까지 고정한다.**
   - 쇼츠는 썸네일이 없어서 위 제목이 곧 썸네일이다(research 13).
   - 첫 프레임에 「무슨 영상인지」가 없으면 이탈한다(영상 16).
   - 훅 텍스트를 끝까지 남겨 둔다(영상 5).
4. **화면 변화는 컷이 아니라 글자 교체로 만든다.**
   - 한국 이슈 쇼츠는 62초에 컷이 1번이고, 화면 변화는 자막 교체가 만든다(research 13).
   - 정보형 영상의 리듬은 1.2~1.3초다(research 13·21).
   - 하드컷이 기본이고, 전환 효과는 필요할 때만 쓴다(영상 19).
5. **소리 없이 봐도 다 이해되게 만든다.**
   - 레퍼런스 릴스는 나레이션이 없다(research 21).
   - 음악은 올릴 때 앱에서 붙인다(영상 20).
6. **사람이 검수할 수 있는 만큼만 만든다.**
   - 이틀에 50편을 만든 사례는 일주일 뒤 전부 내렸다(research 15).
   - 주제·훅·최종 검수를 기계에 넘긴 사례는 예외 없이 결과가 나빴다(research 15).

## 2. 포맷

### 2-1. 모음형 — 「이번 주 돈 안 내고 볼 수 있는 공연·전시」 (자동, 매일 쓸 수 있음)

| 구간 | 길이 | 화면 |
|---|---|---|
| 넘겨 보기 | 0.3초 × N장 | 위 고정 제목 + 실제 포스터가 빠르게 바뀜. 다른 글자 없음 |
| 한 곳씩 | 1.5초 × N곳 | 포스터 통째(아주 느린 확대 2%/초) · 아래 큰 글자 「22일 일요일 오후 5시」 · 장소 · 출처 기관 · 오른쪽 위 `3 / 8` |
| 목록 | 5초 | 8줄 표: 날짜 · 시군 · 짧은 제목. 맨 아래 「예약·잔여석은 공식 안내에서 한 번 더 확인」 · `@picka.news` |

- 생성기: `python collector/tools/make_reel.py <facts 폴더> --out <폴더> --slug <이름>`
  - `--sample`을 붙이면 장면 12컷 PNG만 뽑는다.
  - 무료 행사가 4건 미만이면 만들지 않는다.
- 첫 결과물: `docs/insta/2026-11-19/reel/free_v2.mp4` (8곳, 19.4초).
- 무료가 아닌 주간에는 같은 틀에 제목만 바꾼다. 예: 「이번 주말 공연」, 「아이랑 갈 만한 곳」. 틀(위치·여백·글꼴)은 바꾸지 않는다(브랜드 13절 「일관성」).

### 2-2. 다녀온 곳형 (사람이 찍음, 주 1편 목표)

브랜드 13절 「사람의 흔적」에 해당한다. 비팔로워에게 가장 강한 형식이다.
- 공연장 앞이나 로비, 커튼콜처럼 **찍어도 되는 장면**을 폰으로 세로 3~5컷 찍는다(컷당 2~4초).
- 화면 글자는 위 고정 제목 1줄(「김해 하늬홀, 다녀왔어요」)과 아래 한 줄 후기(주차·줄 길이·분위기)만 넣는다.
- 편집은 인스타 앱이나 Edits 앱(무료)에서 한다. 앞의 빈 시간은 자르고, 클립 사이는 하드컷으로 잇는다(영상 18·19).
- 촬영 허용 여부는 공연장 안내를 따른다. 공연 중 촬영은 하지 않는다.

### 2-3. 쓰지 않는 것

| 형식 | 이유 |
|---|---|
| 퀴즈·룰렛·「0원」 도장 | 2026-11-19 운영자 판정 「AI 티」 |
| CapCut 템플릿 | 누구나 같은 결과라 차별화가 안 된다(영상 20) |

| 무료 스톡 영상 배경(Pexels 등) | 「공식 포스터·권리 확인 사진만」 규칙과 맞지 않는다 |
| TTS 나레이션 | AI 음성은 반응이 낮고(research 15) 티가 난다 |

## 3. 화면 규격 (1080×1920)

| 층 | y 위치 | 내용 |
|---|---|---|
| 위 비움 | 0~170 | 인스타 상단 UI |
| 고정 제목 | 190~360 | 2줄. 1줄은 크림색 66px, 2줄은 빨강 46px(곳 수 · 기간) |
| 본 화면 | 400~1150 | 포스터 통째(contain). 위에 아무것도 얹지 않는다 |
| 때 | 1170~1270 | 84px 굵게. 화면에서 가장 큰 글자 |
| 장소·출처 | 1278~1380 | 42px / 28px |
| 아래 비움 | 1420~1920 | 캡션·버튼 UI. 글자 금지 |
| 오른쪽 | x 920~1080 | 하트·댓글 버튼. 중요한 글자를 두지 않는다(영상 16·18) |

- 색은 브랜드 팔레트만 쓴다: 먹 `#1C1C1C`, 크림 `#F6EFDF`, 빨강 `#D33A2C`, 회청.
- 글꼴은 Pretendard(제목 900, 본문 700)이고, 마침표·쉼표는 뺀다(research 16).
- 한 화면에 글자는 4줄을 넘기지 않는다(research 16).

## 4. 매일 절차 (모음형)

1. **고르기(사람):** 그날 facts에서 무료 행사가 4건 이상인지 본다. 넣을 행사와 제목 문구를 정한다.
2. **포스터 확인:** 긴 변이 900px 아래인 저화질이면 공식 큰 포스터를 찾거나 그 행사를 뺀다(INSTA_DAILY 규칙).
3. **장면 뽑기:** `make_reel.py ... --sample`을 실행한다. 12컷을 시트 한 장으로 이어 붙인다.
   ```
   ffmpeg -f concat -safe 0 -i list.txt -vf "scale=270:480,tile=6x2" -frames:v 1 sheet.png
   ```
4. **눈으로 검수(사람)** — 하나라도 걸리면 게시하지 않는다.
   - [ ] 날짜·요일·시각·장소가 facts·공식 페이지와 같은가(영상 7·9)
   - [ ] 글자가 잘리거나 겹치지 않는가(목록 화면의 날짜 칸이 특히 문제)
   - [ ] 포스터가 그 행사의 것이고 잘리지 않았는가
   - [ ] '경남' 같은 브랜드 금지어가 없는가
5. **굽기:** `--sample` 없이 다시 실행하면 mp4가 나온다(19초 기준 약 3분).
6. **게시(폰):**
   - 인스타 설정 → 미디어 품질 → 「최고 화질로 업로드」를 켠다. 한 번만 하면 된다(영상 18).
   - 릴스로 mp4를 올리고, 음악 버튼에서 「인기 상승」 곡을 붙인다. 볼륨은 낮게(영상 20).
   - 커버 프레임은 목록 화면으로 고른다. 위치 태그를 단다(영상 18).
   - 캡션은 브랜드 10절을 따른다. 첫 문장 모양을 매번 바꾸고, 해시태그는 5개, 행사 계정을 `@`로 태그한다.
7. **기록:** 리포트에 kind `릴스`로 남긴다.

## 7. 근거가 엇갈리는 지점

- **「정지 그림에 확대만 넣으면 저퀄」**(영상 1) vs **사진 슬라이드쇼로 충분**(영상 10·14·20).
  - 피카는 포스터밖에 쓸 수 없다. 그래서 확대만 하지 않고 「번호·때 글자 교체·마지막 목록」으로 시간 구조를 얹었다.
  - 이 방식이 실제로 먹히는지는 2주 측정으로 확인한다.
  - 약하면 다녀온 곳형(실제 촬영) 비중을 늘린다.
- **글자 크기:** 화면의 1/3(영상 14) vs 「생각보다 훨씬 작게」(영상 16). 피카는 「때」 글자만 크게(84px), 나머지는 중간 크기로 둔다.
- **편집 장소:** 폰(영상 18·20) vs 데스크톱(영상 13). 모음형은 PC 자동으로 만들고, 음악 붙이기와 다녀온 곳형은 폰에서 한다.
