## 정기 수집 방식 (AI 최소)

1. 04:00·18:00에 `main.py`가 화이트리스트의 웹 출처를 돈다. URL에 맞는 정의 파일을 찾아 목록을 읽고, 날짜를 규칙으로 뽑고, 링크가 열리는지 확인해 `raw_posts`에 저장한다.
2. 같은 루틴에서 KOPIS 공연 API(경남 전체)를 받는다.
3. 이어서 **자동 공개**를 실행한다(`e80ce12`). 오늘부터 60일 뒤까지 기간이 걸치고, 날짜가 있고, 링크가 열리고, 이미 공개된 행사와 제목·시작일이 겹치지 않는 것만 공개한다. `AUTO_PUBLISH=off`로 두면 공개하지 않고 인박스에 남긴다.
4. 사이트가 개편돼 목록이 0건이 되면 "정의 만료 의심"을 남긴다. 정의 파일 하나만 고치면 되고 파이썬은 고치지 않는다.
5. 새 정의는 `python tools/try_source.py <slug>`로 저장 없이 먼저 시험한다.

## 못 한 것

- **밀양(밀양아리랑아트센터)**: 정의 파일은 만들었지만 넣지 않았다. 이 사이트는 오래된 TLS 설정(짧은 DH 키)을 써서 기본 보안 설정으로는 접속이 거부된다. 그 출처에 한해 보안 수준을 낮춰 접속하는 방법은 권한 분류기가 막았다. 사이트가 고쳐지거나 사용자가 허용하면 넣을 수 있다.
- **양산·고성·합천·하동·산청**: 수집할 공식 일정 페이지를 찾지 못했거나(양산은 자동 접속 차단, 합천은 403), 페이지에 11월 일정이 없다. 이 지역은 KOPIS 공연만 들어온다.
- **경남도립미술관**: JSON 주소는 찾았지만 지금 진행 중인 전시가 0건이라(11.2~11.24 휴관) 이번에는 넣지 않았다.
- **공공데이터 API**(한국관광공사 TourAPI 축제, 한국문화정보원 공연전시, 전국문화축제표준데이터): 엔드포인트는 살아 있지만 data.go.kr 인증키가 필요하다. 키는 사용자가 data.go.kr에서 활용 신청을 해야 받을 수 있다. 키가 생기면 시군 축제를 한 번에 받을 수 있다.
- 진주시 목록의 이미지(`image.do`)는 이미지 파일이 아닌 응답을 돌려줘서 포스터를 받지 못했다. 행사 정보는 정상으로 저장했다.
- 출처마다 제목 표기가 달라 같은 행사가 두 번 공개됐을 수 있다. 중복은 제목과 시작일이 같을 때만 거른다. 예: KOPIS와 창원문화재단에 같은 공연이 다른 제목으로 올라온 경우.
