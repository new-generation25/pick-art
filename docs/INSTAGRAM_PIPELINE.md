# 인스타그램 행사 수집 절차

행사 정보 취득 → 공식 채널 검색 → 공식 정보 등록.

**원칙: 이 앱은 공식 채널에 나오지 않는 소규모 행사·공연을 알리는 것이 목적이다.**
- 공식 채널(시청 공지, 재단·공연장 사이트, 주최 측 공식 계정)이 있으면 그 링크와 날짜를 쓴다.
- 없으면 행사를 올린 게시물 자체를 출처로 공개한다. 조건은 게시물(캡션이나 포스터)에 날짜와 장소가 분명히 적혀 있는 것이다.
- 공식 채널이 없다는 이유로는 빼지 않는다. 빼는 것은 날짜를 알 수 없거나, 경남 밖이거나, 행사가 아닌 글뿐이다.

## 1. 계정의 두 역할

`whitelist`(type=instagram)의 `role` 칸으로 구분한다. 관리자 페이지 › 출처관리 카드에 배지·점수·근거가 나온다.

| role | 뜻 | 쓰임 |
|---|---|---|
| `official` | 지자체, 문화재단, 공연장·미술관·박물관, 축제 조직위의 공식 계정 | 행사 원문을 읽고, 공식 링크로 쓸 수 있다 |
| `informant` | 행사 정보를 자주 올리는 인플루언서·시민·지역 언론 | 행사를 발견하는 용도. 링크·날짜는 공식 채널에서 다시 확인한다 |

전체 목록·점수·탈락 사유는 [collector/instagram_accounts.json](../collector/instagram_accounts.json)에 있다.

## 2. 공식 계정을 찾는 법
1. 기관 홈페이지의 머리·바닥글 SNS 아이콘, JSON-LD `sameAs`, "공식 SNS" 페이지에서 인스타그램 링크를 찾는다.
2. 프로필을 열어 이름·소개가 기관과 맞는지 본다.
3. 홈페이지 링크가 죽은 계정이면(예: 의령군 uiryeonginfo, 함양군 hamyanggun), 인스타그램 검색에서 소개에 "○○군청 공식 계정"이라고 적힌 계정을 쓴다.
4. 해시태그 탐색에서 나온 기관 계정(예: 거창문화재단 gccf_official)은 프로필 이름으로만 확인한 것이라 `score_detail`에 그렇게 적는다.

## 3. 정보 제공자(informant) 선정 기준

**후보를 찾는 법:** 경남 해시태그 20개(`#김해축제` `#창원축제` `#경남축제` `#진주축제` `#김해가볼만한곳` `#창원아이랑` `#경남공연` 등)의 검색 결과에서 최근 게시물(2026-08 이후)의 작성자를 센다. 2회 이상 나온 계정이 후보다.

**측정:** 프로필의 최근 게시물 24개 캡션(그리드 이미지 `alt`)으로 잰다.
- **경남 비중:** 경남 시군 지명이 나온 게시물 수.
- **행사 정보:** 날짜(📅·일시·`11.7.` 형식)와 행사어(축제·공연·전시·행사·체험 등)가 함께 있는 게시물 수.
- **광고:** 협찬·광고·제작지원 표기가 있는 게시물 수.
- **최근 게시:** 최근 게시물 코드로 5주 안에 올렸는지 본다.

**통과 조건(모두 충족):**
- 경남 비중 ≥ 50%
- 날짜와 행사가 함께 적힌 게시물 ≥ 5/24
- 광고 ≤ 25%
- 최근 5주 안에 게시
- 공개 계정이고, 업체 자체 홍보 계정(호텔·식당 등)이 아닐 것

**점수(100점, 관리자 페이지 표시용):**
- 경남 비중 × 40
- 행사 게시물 수(12개면 만점) × 40
- 팔로워 1만 이상 10점, 1천 이상 5점
- 최근 게시 10점
- 광고 비중 × 40 감점

2026-11-01 첫 선정 결과:
- 후보 38개 중 13개가 통과했다(57~95점).
- 탈락 25개는 대부분 맛집 계정이라 행사 게시물이 5개 미만이었다.
- 관광·축제 기관 계정 10개는 `official`로 분류했다.

## 4. 정기 실행 (스크립트 매일 + 주간 검토)

**처음 한 번(사람이 직접):** 수집 전용 브라우저 창을 띄워 인스타그램에 로그인한다. 세션은 `collector/.cache/ig_profile`에 남는다(커밋 안 됨).
```
python tools/collect_instagram.py --login
```

**매일(스크립트):**
```
python tools/collect_instagram.py [--dry-run] [--only=계정1,계정2] [--role=official|informant]
```
- `whitelist`의 인스타그램 계정마다 프로필의 최근 게시물을 열고, 이미 본 게시물(`collector/.cache/insta_seen.json`)은 건너뛴다.
- 게시물 하나를 행사 하나로 본다. 제목은 「」·제N회·행사어가 있는 앞줄, 날짜는 신청·접수가 아닌 첫 일시 줄, 장소는 '장소'·📍 줄에서 뽑는다. 행사가 여러 개 나열된 모음 글은 여러 건으로 뽑는다.
- 이미 공개된 행사와 같은 것은 건너뛴다. 행정 안내·모집·헌혈·스포츠 글도 건너뛴다.
- 결과는 `raw_posts.status='REVIEW'`로 쌓는다. 정기 자동 공개(COLLECTED·PENDING 대상)와 관리자 인박스에는 섞이지 않는다.
- 캡션에 날짜가 없고 행사어만 있으면 "포스터만"으로 표시해 둔다. 검토 때 이미지를 보고 날짜를 넣는다.

**매일(계정 유지 + 새 계정 탐색):**
```
python tools/discover_instagram.py [--dry-run] [--max-new=15] [--max-rescore=10]
```
- **탐색 대상(정보 취득처):** 각 지역에서 활동하는 지자체, 문화예술 공공기관, 박물관·미술관, 재단(→ `official`), 협회·예술단체·문화단체(→ `group`), 예술단체 대표·실무자 개인(→ `artist`). 맛집·여행 인플루언서는 새로 넣지 않는다(기존 `informant` 13개는 유지만 한다).
- **후보 출처:** 수집한 게시물 캡션의 @계정(기관·단체가 언급하면 가중치 2), 그날 차례인 예술 해시태그 4개(#경남연극 #김해공연 #창원전시 #경남국악 #경남버스킹 등 33개를 돌아가며)의 게시물 작성자.
- **역할 판정:** 프로필 이름·소개 글로 정한다.
- **통과 기준:** 경남 비중(기관 ≥50%, 단체·개인 ≥30%), 날짜+행사 게시물 ≥2/24, 광고 ≤25%, 5주 안에 게시. 통과하면 `whitelist`에 역할·점수와 함께 넣는다. 탈락한 계정은 30일 동안 다시 보지 않는다.
- **유지:** 채점한 지 오래된 계정부터 하루 10개를 다시 채점한다. 단체·예술인·인플루언서가 두 번 연속 기준에 못 미치면 `dormant`(휴면)로 바꿔 수집에서 뺀다. 지우지는 않는다. 기관은 휴면시키지 않는다.
- 팔로우는 자동으로 하지 않는다.

**매주(검토):**
```
python tools/review_instagram.py --export
python tools/review_instagram.py --apply collector/review/instagram_<날짜>.json [--dry-run]
```
- `--export`: 기존 행사와 중복된 후보는 `DUPLICATE`로 정리하고, 남은 후보를 `collector/review/instagram_<날짜>.json`으로 쓴다.
- 항목마다 `decision`을 채운다.
  - `publish`: 공개. 공식 채널을 찾았으면 `official_url`에 넣고, 없으면 게시물로 공개한다.
  - `reject`: 행사가 아니거나, 경남 밖이거나, 날짜를 알 수 없음.
  - 빈칸: 다음 주에 다시 본다.
- 제목·날짜·장소는 이 파일에서 고쳐 쓴다.
- `--apply`: 내용을 반영하고 포스터를 올린 뒤, `publish_verified`와 같은 검사(날짜·링크·중복)로 해당 항목만 공개한다.

## 5. 수집 절차 (사람·Claude가 직접 할 때)
1. **취득:** `official`·`informant` 계정의 최근 게시물(지난 실행 이후)을 읽는다. 캡션에서 `📅/일시` 줄과 `📍/장소` 줄을 행사 후보로 뽑는다. 캡션에 날짜가 없고 포스터에만 있으면 "이미지 전용"으로 따로 표시한다.
2. **대조:** `events`에 같은 행사가 있는지 본다. 기준은 시작일이 같고, 정규화한 제목 한쪽이 다른 쪽을 포함하는지다. 있으면 건너뛰고, 포스터가 비어 있으면 게시물 이미지로 채운다.
3. **공식 채널 검색:**
   - `official` 계정 게시물이면 그 게시물이 곧 공식 채널이다.
   - `informant` 게시물이면 주최 측 공식 채널을 찾는다. 시청 공지·보도자료, 재단·공연장 사이트, 축제 공식 사이트, 주최 측 공식 인스타그램 순서다. 없으면 게시물 자체를 출처로 쓴다(날짜·장소가 분명할 때). 공식 채널이 없다고 빼지 않는다.
4. **등록:**
   - 공식 링크·날짜로 `collector/curated/<달>_<출처>.json`을 쓴다(형식은 기존 curated 파일과 같다).
   - `python tools/add_curated.py <파일>`을 실행한다.
   - `python tools/publish_verified.py <from> <to> --dry-run`을 먼저 돌려 다른 출처 행이 함께 발행되지 않는지 확인한 뒤, 실제로 실행한다.

## 6. 제약
- `instaloader` 무로그인 요청은 이 PC에서 첫 요청부터 429로 실패한다. 인스타그램 내부 API(`web_profile_info`, `topsearch`)도 429/404다.
- 로그아웃 브라우저로도 프로필 최근 12개와 embed 캡션을 읽을 수 있다. 다만 2026-11-01 시험에서 계정 수십 개를 읽고 나니 프로필이 로그인 화면으로 돌아갔다(`is_from_rle`). 그래서 정기 수집은 `--login`으로 만든 세션을 쓴다.
- 게시물 작성자는 `/p/<코드>/embed/captioned/`에서, 원본 이미지는 `/p/<코드>/media/?size=l`에서 로그인 없이 받을 수 있다.
- 팔로우는 짧은 시간에 50회쯤 하면 "나중에 다시 시도하세요"로 막힌다. 하루에 나눠서 한다.
