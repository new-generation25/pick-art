# 피카 화면 시안 3안 (2026-11-26)

개선 계획(`docs/plan/design_plan/index.html`)의 D1·D2를 세 시안에 똑같이 넣고, 카드 모양과 우편 그림을 얼마나 쓰는지로 방향을 나눴다. 사이트 코드(`frontend/`)는 고치지 않았다.

- 비교 페이지(Artifact, 비공개): https://claude.ai/artifact/1hPVf8NTzZK9EYWAMNXjvL
- 한 파일로 보기: [mockups_standalone.html](mockups_standalone.html) — 포스터 축소본·글꼴을 base64로 넣었다
- 원본: [mockups.html](mockups.html) — `img/`·`fonts/` 상대 경로. `?only=A-home`처럼 붙이면 그 화면만 375×812로 연다
- 다시 만들기: `python build.py` (글꼴 줄이기 → 한 파일 생성, `captures/results.json`이 있으면 주석의 «캡처 확인» 줄을 채움)

| 시안 | 생각 | 화면 |
|---|---|---|
| A 엽서함 | 카드 = 엽서 뒷면, 우표 칸 = 관람료, 소인 = 날짜. 지금 카드 구조를 살림 | 홈 · 상세 · 공간(김해서부문화센터) |
| B 우표첩·동네 지도 | 3열 우표 격자(같은 칸 = 같은 무게), 지역 고정 주소와 동네 지도 | 지역 홈(/region/김해) · 상세 · 내 주변 |
| C 편집 목록 | 번호·시각·제목·«피카가 본 이유» 중심, 포스터는 작게 | 홈 · 상세 · 단체(어댑터 시어터) |

## 데이터

- picka.news에 11/26 공개된 실제 행사(제목·날짜·장소·관람료·시각·포스터). 건수(전체 700 · 오늘 64 · 이번 주 135, 김해 71)는 `lib/feedOrder.ts` 규칙으로 센 값이다.
- «피카가 본 이유» 문장은 시안용 예시다. DB에 이 칸을 쓴 행사가 아직 없어서 각 행사 안내문의 사실로만 지었다.
- 포스터 원본(`img/`), 줄인 글꼴(`fonts/`), 캡처(`captures/`)는 커밋하지 않는다. 포스터는 주최 측·KOPIS 자료다.
