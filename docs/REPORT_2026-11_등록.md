### 등록 기준

`collector/tools/publish_verified.py`가 아래 셋을 모두 통과한 것만 `events`에 PUBLISHED로 넣었다.

1. 기간이 11월 1일~30일과 겹친다.
2. 원본 링크가 지금 HTTP 400 미만으로 열린다. KOPIS는 예매처 → 공연장 홈페이지 → KOPIS 상세 순서로 열리는 링크를 고른다.
3. 같은 행사가 여러 출처에 있으면 하나만 남긴다(제목 정규화 + 시작일). 우선순위는 KOPIS > 기관 게시판 > 큐레이션. 겹친 4건은 `DUPLICATE`로 표시했다.

11월과 겹치지 않는 101건과 날짜를 못 찾은 1건은 `raw_posts`에 COLLECTED로 남겨 두었다(지우지 않음). 전체 판정 목록은 `docs/publish_2026-11-01_2026-11-30_dryrun.json`에 있다.

## 못 한 것과 이유

- **남해·하동·산청 0건.** KOPIS 경남 수집분 122건 중 이 세 지역은 0건이었고, 이 지역 문화예술회관 게시판은 정의 파일을 아직 만들지 않았다. 다음에 할 일: 군 단위 문화예술회관 게시판을 `tools/probe.py`로 점검해 정의 파일을 추가한다.
- **경남도립미술관 홈페이지 접속 불가.** 공식 인스타그램으로 대신 확인했다. 미술관이 11.2~11.24 휴관이고, 다음 전시는 날짜가 공개되지 않아 넣지 않았다.
- **거제섬꽃축제, 진주국제농식품박람회.** 2026년 공식 일정을 찾지 못해 넣지 않았다.
- **인스타그램 해시태그 검색.** 해시태그 결과가 지난 인기 게시물 위주라 날짜를 확정할 수 없었다. 기관 공식 계정 게시물만 근거로 썼다.
- 정렬은 시작일순이라, 몇 달째 진행 중인 상설 전시가 목록 맨 앞에 온다. "곧 시작하는 것 먼저"로 바꿀지는 판단이 필요해 그대로 두었다.

## 사용자가 결정할 것 (손대지 않음)

- **보안**: `events` 등 테이블의 RLS가 "Allow All"이다. 관리자 화면에 권한 검사가 없다. 외부 공개 배포 전에 막아야 한다.
- **구글 OAuth**: 앱이 테스트 모드다(테스트 사용자 3명만 로그인 가능). 프로덕션 게시에는 홈페이지·개인정보처리방침 URL이 필요하다. 이전 클라이언트 보안 비밀(`****9Grw`)이 아직 사용 설정 상태다.
- **카카오 로그인**: Supabase 공급자를 켜지 않았다.
- **텔레그램 알림**: 토큰이 자리표시자라 꺼져 있다.
- **Turbopack**: 상위 폴더의 `package-lock.json` 때문에 루트를 잘못 잡고 메모리가 폭증한다. 지금은 webpack 모드(`pick-art-frontend-webpack`)로 실행한다. 상위 lockfile을 지울지는 사용자 판단이다.
- 브랜치 `revive/2026-10`은 푸시하지 않았다.
