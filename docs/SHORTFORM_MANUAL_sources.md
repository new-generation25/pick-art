## 서로 어긋나는 주장

1. **정지 이미지 + 확대 효과**: 1번은 「멈춘 그림에 확대만 넣으면 저퀄」이라고 하고, 10번(박자 맞춘 사진 슬라이드쇼)·14번(정지 배경+텍스트 슬라이드)·20번(사진 1장 템플릿)은 정지 이미지만으로 릴스를 만든다. 포스터만 쓰는 pica는 「확대만」이 아니라 박자 전환·텍스트 순차 등장·슬라이드 번호처럼 **정지 이미지 위에 시간 구조**를 얹는 쪽이 근거가 있다.
2. **폰 vs 데스크톱**: 13번은 「폰 편집을 그만두라」, 18번은 앱 안 편집이 빠르고 쉽다며 Edits 앱을 권하고, 20번은 폰 CapCut 템플릿으로 끝낸다.
3. **훅 비중**: 16번은 「안 되는 가장 큰 단일 이유가 나쁜 훅」, 15번은 「콘텐츠 소비의 80%가 훅 때문」(출처 없음). 17번은 「훅에 너무 집착하지 말고 전달할 메시지가 먼저」.
4. **편집 밀도**: 12·13번은 「시청자는 시각 요소가 더 많은 영상을 원한다」며 그래픽·줌·팝업을 쌓고, 15번은 「대본형 고편집보다 날것 이야기형이 더 잘 된다」, 14번 ③은 「애니메이션은 적게, 사람이 만든 느낌」.
5. **텍스트 크기**: 14번은 훅 제목을 화면 약 1/3로, 16번은 「생각보다 훨씬 작게」, 12번은 하단 1/3·크기 60.
6. **텍스트 노출 시간**: 14번은 「읽기 직전에 넘겨서 다시 보게」, 5번은 「훅 텍스트는 끝까지 계속 보이게」, 19번은 텍스트 2초+페이드 1초.
7. **길이**: 9번은 5~10초(짧을수록 끝까지 봄), 17번은 목적 따라 최대 180초까지(전문성은 길게), 18번은 기본 60초·최대 3분. 2번은 장면당 약 10초.
8. **AI 사용**: 1·2·4·16번은 AI 이미지(또는 AI 첫 프레임)를 쓰고, 9번은 AI가 포스터 글자를 깨뜨리는 실패를 보여 주고, 17번은 시청자가 AI 영상을 선호하지 않는다고 말한다. pica는 브랜드 규칙상 AI 이미지 불가 — 9·17번이 그 규칙을 뒷받침한다.
9. **자동 자막 비용**: 19번은 CapCut 자동 캡션이 Pro 유료라고 하고, 18번은 인스타 앱 안 AI 자막을 무료로 쓴다.
10. **편집 순서**: 11번은 「구간 하나를 완전히 끝내고 다음으로」, 8번은 「전체를 여러 번 훑으며 다듬고, 뒷부분에도 같은 시간」.

## 무료로 바로 적용할 방법

pica 조건(공식 포스터만, AI 이미지 금지, 무료 도구)에 맞는 것만 골랐다. 괄호는 근거 영상 번호.

**올리기 직전 설정·점검 (인스타 앱, 무료)**
- 인스타 설정 → 미디어 품질 → 「최고 화질로 업로드」 켜기. 기본값이 꺼져 있다고 함 (18).
- 커버 프레임 지정, 프로필 그리드 크롭 확인, 공연장 위치 태그 (18).
- 게시 전 3가지: 포스터·자막의 날짜·장소·가격이 원문과 같은지, 마지막 장면까지 글자가 안 바뀌었는지, 길이 (9). 사실 확인 후 대본 (7).
- 세이프존: 오른쪽 하트·댓글 버튼, 하단 캡션 영역에 글자를 두지 않기. 인스타 편집기가 가이드선을 보여 줌 (16, 18).

**포스터만으로 만드는 형식 (무료 도구)**
- 박자 슬라이드쇼: CapCut PC에서 음악 → Auto marks beats → Beat 1/2 → 자동 스냅으로 포스터 끝을 박자에 맞춤 (10). 비트 기능의 무료 여부는 영상이 말하지 않아 실제 무료 계정으로 확인 필요.
- 타이포 슬라이드형: 단색 배경 + 장당 정보 1개(제목/날짜/장소) + 「1/4」 번호 + 같은 전환 반복 (14). 포스터 원본 → 정보 슬라이드 → 다시 포스터 식으로 엮을 수 있음.
- 포스터는 그대로 두고 텍스트만 별도 레이어로 (9). 훅 텍스트는 끝까지 유지 (5) 또는 순차 등장 (14) 중 하나를 정해 고정.
- 첫 프레임: 「무슨 영상인지」 맥락 한 줄 + 질문 하나 (16, 15). 정체(공연명)를 첫 프레임에 다 주지 않고 뒤에 공개하는 방식도 있음 (16).

**코드로 자동 생성 (완전 무료 구성)**
- Python + Pillow(텍스트·포스터 합성) + FFmpeg(`subprocess`) → 1080×1920 (6). 여기에 무료 TTS(Google TTS 또는 Edge TTS)를 붙이면 내레이션까지 무료 (1, 4).
- 자막 타이밍은 TTS 음성 길이를 재서 계산 (1). 이미 만든 건 상태 칸으로 건너뛰기 (2).
- HTML/코드 애니메이션 렌더는 Remotion(3)·HyperFrames+GSAP(7)가 나오지만, 3번은 요금 미언급, 7번은 Claude Pro 유료 플랜 전제다.

**사람이 만든 느낌을 내는 편집 문법 (도구 무관, 무료)**
- 길이 대비: 긴 컷과 1초 미만 컷 섞기, 균일한 간격 피하기 (8, 11, 13).
- 음악부터 고르고 「쌓임 → 잦아듦 → 다시 쌓임」 곡선에 맞춰 배치. 잦아드는 구간에 가장 강한 장면 (8).
- 효과음 세트를 정해 반복, 소리 겹치기 (8, 13).
- 하드컷 기본, 전환은 필요할 때만 (19). 튀는 색 하나만 맞추기 (19).
- 템플릿 그대로 쓰기는 피하기 — 누구나 같은 결과라 차별화가 약하다고 영상 스스로 경고 (20).

**무료 자막·음원**
- 인스타 앱 안 AI 자동 자막 (18). CapCut 자동 캡션은 Pro 유료라서 → Vrew에서 SRT 받아 CapCut에 불러오기 (19).
- BGM: 인스타 업로드 단계에서 앱 음원(인기 상승 곡) 붙이기 (20, 14). 템플릿 원곡은 저작권 때문에 끄고 올림 (20). 외부 앱에서 음악을 넣어 굽는 경우 상업 이용 조건은 이번 20편에서 다루지 않아 따로 확인해야 한다.
- 참고용 무료 레퍼런스: 메타 광고 라이브러리, 핀터레스트, 인스타 인기 음원 순위 (17).

**적용하면 안 되는 것 (브랜드 규칙과 충돌)**
- AI 이미지·AI로 포스터 움직이기·AI 첫 프레임 재연 (1, 4, 9, 16).
- Pexels·Pixabay 무료 스톡 배경 (4) — 무료지만 「공식 포스터만」 규칙에 맞는지는 사용자 판단 필요.
