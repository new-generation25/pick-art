## 무엇이 생겼나
- 공개 화면 `/nearby`: 「내 위치로 찾기」(누를 때만 위치를 묻는다) 또는 지역 고르기(경남 18 시군 · 부산 16 구군, 시청·구청 기준)로 이번 주 행사를 **직선거리** 가까운 순으로 보여 준다. 기간(오늘·주말·이번 주·2주)·거리(3·10·30km)·분야 필터, 행사마다 「네이버지도 길찾기」 버튼 하나(이동수단은 네이버지도 안에서 고름, 2026-11-21 운영자 결정).
- 전체 피드 필터 위에 「내 주변 가까운 순으로 보기」 입구.
- 관리자 `/admin/venues`: 확인 대기 장소의 후보 고르기·좌표 붙여넣기·찾을 수 없음·장소 합치기.
- 수집기: `collector/tools/geocode_venues.py`가 정기 루틴 끝에 새 행사 장소 좌표를 채우고 알림에 한 줄 보고.
- DB: `venues` 표, `events.venue_id`, 공개 뷰 `public_venues`(확정 좌표만, 읽기 전용).

- 위치 허용(광안리 좌표 대체): 240m → 910m → 1.3km 순, 「내 위치 기준」, 거리 표시 210 · 확인 안 됨 27.

- 위치 거부: 오류 화면 대신 안내 + 지역 고르기. 「부산 수영구」 선택 → 「부산 수영구 중심 기준」 410m부터, 다시 열어도 유지.
- 응답 없음: 「위치 확인 중…」 → 6초 뒤 「위치를 받지 못했어요」 + 지역 고르기.

## 알아 둘 것
- 좌표 검색은 네이버 클라우드 콘솔 NAVER API HUB 「지역」(Application `pica`, 이권 계정). 「한시적 무료, 유료 전환 시 사전 공지」. 하루 25,000회·월 775,000회 한도, 정기 루틴 사용량은 하루 수 건.
- 키는 `collector/.env`(`NAVER_SEARCH_CLIENT_ID`·`SECRET`)에만 있고 사이트(Vercel)에는 없다.
- 공개 행사에 같은 공연이 두 줄로 들어 있는 경우가 보였다(예: 「연극 <임대아파트>」와 「임대아파트 [부산]」). 이번 기능과 별개인 수집 중복이다.
- Vercel 프로젝트 `pick-art-pica`는 이 작업 전 커밋부터 빌드가 실패하고 있다(`pick-art`는 성공).
