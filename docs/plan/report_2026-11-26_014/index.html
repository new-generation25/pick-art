직접 해 주셔야 할 것

  • 운영자 Chrome(MAX)에 열려 있는 Supabase SQL 편집기 탭 2개를 닫아 주세요 — X를 누르고 «나가기/Leave». 두 탭의 SQL은 이미 적용됐고, 제 도구로는 «저장하지 않은 변경» 확인창 때문에 닫히지 않습니다.
  • 운영자 로그인한 상태에서 picka.news/me — 내 지역·관심 분야를 바꿔 저장되는지, 찜한 행사가 보이는지.
  • 운영자 관리자 대시보드에서 «세부 판정 대기»(지금 진행 중·예정 행사 중 단서 없는 것)를 시간 날 때 골라 주세요. 고르면 «운영자 확정»으로 남고 자동 판정이 덮어쓰지 않습니다.
  • 운영자 같은 대시보드의 «안내 그림 후보»와 행사 상세의 «안내 그림으로 표시 / 풀기»·«세부 갈래» 칸이 보이는지 한 번 확인.
  • 운영자 공간·단체 페이지의 «협약 맺음» 버튼 — 실제 협약이 생기면 그때 누르면 됩니다.

알아 둘 것

  • 바깥 주소(KOPIS 등) 포스터 413건은 그 서버가 요청을 거절해 그림 지문을 채우지 못했습니다. 지금까지 찾은 안내 그림은 모두 피카 저장소 쪽입니다.
  • 첫 화면 속도는 바꾸기 전 평균 1,144ms입니다. 바꾼 뒤 값은 다음에 같은 방법으로 잽니다.
  • 작업 브랜치와 main은 기록이 갈라졌습니다(main은 014만 옮겨 담음). 내용은 같고, 작업 브랜치에 main을 합쳐 다음 배포가 막히지 않게 했습니다. 사업 문서는 여전히 공개 저장소에 올라가지 않았습니다.
  • 세부 판정 규칙은 collector/rules/genre_rules.json 한 파일입니다. 낱말을 더하고 python tools/classify_genre.py --apply를 돌리면 다시 매깁니다(운영자가 고른 값은 그대로).
  • 판정 대기 217건의 대부분은 «송년음악회», «○○ 개인전»처럼 제목에 갈래 단서가 없는 행사입니다. 일부러 추측하지 않았습니다(헌장 I).
