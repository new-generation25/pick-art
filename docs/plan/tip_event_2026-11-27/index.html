숨은 행사 제보 — 만들었고, 운영에는 아직 올리지 않았습니다

로그인 없이 «행사 이름 + 링크나 사진 하나»로 제보하는 화면, 공개 화면 아래의 제보 띠, 커피 쿠폰 연락처(선택·동의) 처리까지 구현하고 로컬에서 확인했습니다.

개인정보처리방침제보 = 회원 계정로그인 없는 제보·사진(1년)·쿠폰 연락처(보낸 뒤 삭제, 최대 90일)·표시 이름을 적고 변경 고지에 한 줄 추가

공개 전 확인은 그대로입니다. 제보는 «검토 대기»로만 쌓이고, 운영자가 원문을 확인해 «행사로 등록»해야 공개됩니다(헌장 I).

화면 (로컬 빌드, 폭 375px)

확인한 것과 못 한 것

확인함

  • 접수 함수: 익명 접수, 이름만 → 거절, 동의 없는 연락처 → 거절, 같은 이름·링크 두 번 → 거절, 익명이 제보 표를 읽으면 0줄, 회원의 오류 신고는 지금처럼 통과 (운영 DB에서 시험 뒤 전부 되돌림)
  • 제보 화면: 로그인 문턱 없음, 검사 문구 4종, instagram.com/p/…처럼 http 없이 붙인 주소도 받음
  • 띠: 홈·행사 상세·소개·단체 안내에 있고 제보·리플렛·로그인 화면에 없음
  • 폭 375px에서 홈·행사 상세·제보 화면 가로 넘침 0
  • 정리 작업: 90일 지난 연락처·1년 지난 사진을 지우는 시험 통과

아직 확인 못 함 (배포해야 볼 수 있음)

  • 제보가 실제로 저장되고 관리자 화면에 보이는 것
  • 사진 올리기(저장소 권한)와 관리자의 «사진 보기»
  • «쿠폰 보냄 · 연락처 지우기» 뒤 연락처가 비는 것
  • 행사 화면의 «제보: ○○» 줄

배포하면 시험 제보 2건(링크 / 사진+연락처)으로 위 네 가지를 운영 주소에서 확인하고, 시험 제보는 «반영 안 함»으로 닫습니다.

발견했지만 고치지 않은 것

  • 개인정보처리방침 「처리 목적」에 «뉴스레터와 키워드 알림 메일 발송»이 남아 있습니다. 이 기능은 11/27에 없앴습니다(변경 고지에는 적혀 있음). 이번 요청 범위 밖이라 그대로 두었습니다.
  • 휴대폰 홈 화면 맨 아래에서 떠 있는 «지도» 버튼이 꼬리말의 저작권 줄을 가립니다. 이번 변경과 무관하게 원래 있던 모습입니다.

🟩 직접 해 주실 것

  1. 배포하려면 이 세션(피카 앱 개선)에 «배포해»라고 적어 주세요. main 배포와 운영 DB 변경은 운영자 본인의 말이 있어야 해서 제가 먼저 하지 않았습니다. 받으면 DB 적용 → 배포 → 운영 주소 시험까지 이어서 합니다. 017 세션의 제목 노출 규칙 커밋(수집기 코드, f1920b5)도 이때 main에 함께 올라갑니다.
  2. MAX 크롬에 Supabase SQL 편집기 탭이 하나 열려 있습니다. 탭을 닫을 때 «사이트에서 나가시겠습니까?»가 뜨면 «나가기»를 눌러 주세요. 페이지가 확인 창을 띄워서 제가 닫지 못했습니다(안의 시험 SQL은 지워 두었습니다).
  3. 배포 뒤 매주: 관리자 › 신고·제보 → «쿠폰 대상»에서 그 주에 반영한 제보의 연락처 확인 → 5명에게 쿠폰 발송 → 줄마다 «쿠폰 보냄 · 연락처 지우기». 쿠폰 구매·발송은 돈이 나가는 일이라 운영자 몫입니다.

🟩 꼭 확인할 것

  1. 아래 숫자는 운영자 결정이 아니라 제가 정한 기본값입니다. 바꾸고 싶으면 말씀해 주세요 — 로그인 없는 제보 하루 40건(사이트 전체), 사진 10MB 이하, 쿠폰 연락처 보관 최대 90일, 제보 사진 보관 1년.
  2. 동의 문구: «커피 쿠폰을 보내는 데만 쓰고, 보낸 뒤 지워요. 쿠폰을 받지 못한 연락처도 90일 뒤 지웁니다. 이 내용으로 연락처를 받는 데 동의해요.»
  3. 띠 문구: «피카에 없는 행사, 알려 주세요 — 매주 5명께 커피 쿠폰을 드려요. 행사 이름과 링크(또는 사진) 하나면 돼요.»
  4. 「같은 사람 한 주 1장」은 자동으로 묶지 않습니다. 연락처를 보고 운영자가 가립니다.
  5. 카카오톡 채널로 온 제보는 연락처를 받지 않습니다. 그 제보자에게 쿠폰을 주려면 채널 1:1 채팅으로 건네야 합니다.
