## 확인이 필요한 것 (운영자)

1. **포스터 없는 행사에 출처 페이지 대표 이미지(og:image) 붙이기**: 헌장 I은 «현장 사진이나 대표 사진을 포스터처럼 쓰지 않는다». og:image는 기관 로고·건물 사진인 경우가 많다. → 그대로 두거나(지금처럼 «포스터 없음»), «포스터가 아닌 대표 이미지»로 표시를 달리해 쓰는 안 중 선택 필요.
2. **오류 신고·제보를 로그인 없이 받을지**: 로그인 없이 받으면 참여가 쉽지만 스팸을 막을 장치(하루 한도·숨은 칸)가 필요하다.
3. **순서**.
