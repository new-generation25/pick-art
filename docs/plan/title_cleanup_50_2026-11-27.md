# 행사 제목 정리 — 50건 원래안·수정안 (2026-11-27)

운영자 결정(11/27): 제목에는 원제와 부제만 노출한다. 회차·연도는 부제로 보고 남긴다. 원래 노출 형식은 유지한다. 꺾쇠·<>가 든 제목은 그대로 둔다. **판단이 애매하면 그대로 둔다.**

자동으로 걷어내는 것은 두 가지뿐이다.
1. 제목 끝 대괄호 안이 **모두** 지역 이름인 꼬리표: «[부산]», «[부산 영도]», «[김해]». 대괄호 안에 다른 말이 섞이면 그대로 둔다(«[플레이 미, 피아노 김해]», «[더 드레서]»). 괄호 덧말은 남긴다: «[부산 (앵콜) ]» → «(앵콜)»
2. 제목 끝의 «행사 안내»·«개최 안내»

대상: 운영 DB 공개 행사 중 출처를 돌아가며 고른 50건. 바뀌는 것은 굵게.
