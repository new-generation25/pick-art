# 인스타그램 매일 게시 절차 (@picka.news, 매일 10:00)

예약 작업 「pick-art 인스타 매일 10개 게시」가 이 문서를 그대로 따른다. 사람이 손으로 돌릴 때도 같다.
2026-11-16 운영자 지시: 부산·경남 소식으로 넓혀 매일 10개씩, 오전 10시에 자동 게시.

## 지켜야 할 것 (먼저 읽기)

- [docs/BRAND_GUIDE.md](BRAND_GUIDE.md)와 [.specify/memory/constitution.md](../.specify/memory/constitution.md)를 따른다. 특히 **공식 출처에서 확인한 사실만** 쓴다.
- **게시물마다, 올리기 직전에 @picka.news 계정인지 확인한다.** Chrome 확장이 개인 계정(@socialceo4) 브라우저로 저절로 넘어간 일이 있다(2026-11-16 두 번). 확인이 안 되면 그날 게시를 멈춘다.
- 확인이 안 된 행사는 올리지 않는다. 10개를 못 채우면 채운 만큼만 올린다. 숫자를 채우려고 확인 안 된 행사를 넣지 않는다.
- 같은 행사를 두 번 올리지 않는다(`docs/insta/posted.json`).
- 데이터 삭제·수집기 설정 변경·배포는 하지 않는다. 이 작업은 고르기·확인·제작·게시·기록만 한다.

## 1. 후보 고르기

- 작업 폴더: `F:\projects\pick-art`. 산출물 폴더: `docs/insta/<YYYY-MM-DD>/` (git 제외 폴더).
- `events`에서 `status=PUBLISHED`, 지역이 경남 18개 시군 또는 `부산`, 포스터(`poster_image_url`)가 있는 행사.
- 우선순위:
  1. 오늘~3일 안에 **시작하거나 하루만 열리는** 공연·축제·체험
  2. 7일 안에 개막하는 전시, 7일 안에 끝나는 전시("마지막 주")
  3. 무료·아이 동반·야외
- 섞기: 한 지역 최대 3개, 한 기관 최대 2개, 공연만 10개가 되지 않게 분야를 섞는다. 부산과 경남을 모두 넣는다.
- `docs/insta/posted.json`에 있는 `event_id`는 뺀다. 파일이 없으면 `[]`로 만든다.
- 포스터가 '이미지 준비중' 같은 대체 그림이면 원문 페이지의 포스터를 받아 쓰고, 그것도 없으면 그 행사는 뺀다.
- **저화질 포스터 규칙** (2026-11-17 운영자 지시): 포스터 원본의 **긴 변이 700px 미만**이면 저화질로 본다. 표지는 포스터를 약 925px 높이로 그리므로 이보다 작으면 1.3배 넘게 늘어나 흐려진다.
  - 먼저 고화질을 찾는다: 공식 페이지의 이미지들(`naturalWidth`·`naturalHeight`로 크기 확인), 상세 본문 이미지, 첨부파일, 예매처(인터파크·예스24·NOL 등) 상세.
  - 찾으면 `docs/insta/<날짜>/posters/<번호>_<짧은이름>.jpg`로 받아 facts의 `poster`에 그 경로를 넣는다. **같은 포스터여야 한다.** 리플릿 펼침면·상세 안내 이미지를 잘라 쓰지 않는다.
  - 끝내 긴 변 700px 이상인 포스터가 없으면 그 행사는 **뽑지 않는다**(보고의 「뺀 행사와 이유」에 크기와 함께 적는다).
  - 예: 영화의전당 「한낮의 유U;콘서트」 DB 포스터 190×267 → 공식 페이지 본문 1436×2022로 교체.

## 2. 사실 확인 (행사마다)

- `original_url`(공식 페이지)을 내장 브라우저(`mcp__Claude_Browser__*`)로 열어 `document.body.innerText`에서 날짜·시간·장소·요금·관람 연령·문의를 읽는다.
- 인스타그램 게시물이 출처인 행사는 내장 브라우저로 열리지 않는다. DB `description`(수집한 캡션)과 포스터 이미지를 직접 읽어 확인한다.
- DB 값과 공식 값이 다르면 공식 값을 쓴다. 날짜가 서로 어긋나 판단이 안 서면 그 행사는 뺀다.
- 공식 안내에 없는 칸은 facts에 `"-"`를 넣어 비운다(예: 요금이 안 적혀 있으면 `"price": "-"`). DB의 추정값(무료 등)이 들어가지 않게 하기 위해서다.

## 3. 제작

- 행사마다 `docs/insta/<날짜>/facts/<번호>_<짧은이름>.json`을 쓴다. 키는 `collector/tools/make_insta_cards.py` 첫머리 주석과 같다. 예시: `docs/insta/2026-11-3주/facts/`.
  - `hook`: 3줄 이내, 때·혜택 중심. `chip`: 날짜. `kicker`: `지역 · 분야`.
  - `hashtags` 5개: 시군(또는 부산) 2 + 분야 1 + 상황 1 + `#피카문화`.
  - 캡션 첫 문장 모양을 게시물마다 바꾼다(브랜드 가이드 13절).
- 렌더링: `cd collector` 후
  `PYTHONIOENCODING=utf-8 python tools/make_insta_cards.py <event_id> --facts <json> --out docs/insta/<날짜> --slug <번호>_<짧은이름>`
- 게시용 캡션: `_caption.txt`에서 `----- 예비 해시태그` 이하를 잘라낸 본문.
- 표지 PNG를 한 장씩 열어 글자 넘침·포스터 잘림이 없는지 본다.

## 4. 게시 (Claude in Chrome)

게시물마다 아래를 처음부터 한다.

1. `list_connected_browsers` → @picka.news가 로그인된 브라우저를 `select_browser`(2026-11-16 기준 "Browser 1", deviceId `03e1d81e-a112-4388-8679-3b38082b7a95`. 바뀌었으면 연결된 브라우저마다 확인).
2. `tabs_context_mcp {createIfEmpty:true}` → `https://www.instagram.com/` 이동 → 페이지 링크 중 프로필 링크가 `/picka.news/`인지 확인. **아니면 멈춘다.**
3. 왼쪽 「만들기」 → 「게시물」 → 파일 입력(find로 ref) → `file_upload`로 `jpeg_for_api/<slug>_01~05.jpg` 5장.
4. 자르기: 대화상자 안 `svg[aria-label="자르기 선택"]` 버튼 → `4:5`. 화면을 찍어 포스터가 잘리지 않았는지 본다.
5. 대화상자 안 「다음」 두 번(좌표 말고 버튼 글자로 찾아 누른다. 바깥을 누르면 '게시물 삭제' 창이 뜬다 — 그때는 「취소」).
6. 캡션 칸(`[contenteditable=true]`)에 붙여넣기(ClipboardEvent paste) → 글자 수·끝 해시태그 확인.
7. **대화상자에 `picka.news`가 보이는지 다시 확인** → 「공유하기」 → "게시물이 공유되었습니다" 확인.
8. 다음 게시물까지 3분 이상 띄운다.

멈출 때:
- 계정이 picka.news가 아니다, 로그인 화면이 나온다, "작업이 차단됨"·"나중에 다시 시도" 같은 경고가 나온다 → 그 자리에서 멈추고 남은 게시물은 올리지 않는다.
- 작업이 끝나면 내가 연 탭을 모두 닫는다.
